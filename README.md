# Titre : Jeu du pendu en Java

## Jeu du pendu (Exercice dans le cadre de la formation CDA)

## Auteur : Séverine Hori Maitrehut

## Structure des données
Application console développée en Java.
Contrainte donnée par le formateur : interdiction de créer des objets, et d'utiliser des exceptions.
Le projet utilise donc les collections Java pour représenter les données.
